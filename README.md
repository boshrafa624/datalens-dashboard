# DataLens — لوحة تحليل البيانات

تطبيق Python تفاعلي باستخدام Streamlit لتحليل بيانات تجريبية أو ملف CSV، مع فلترة وإحصائيات وصفية ورسوم تفاعلية.

## الميزات
- توليد بيانات موظفين وهمية دون الحاجة إلى خدمة خارجية.
- رفع ملفات CSV وتحليلها ضمن الواجهة نفسها.
- عرض عدد السجلات والأعمدة والقيم المفقودة والصفوف المكررة.
- المتوسط والوسيط والانحراف المعياري والمدى والإحصائيات الوصفية.
- فلترة الأعمدة الفئوية.
- Bar, Line, Pie, Histogram وScatter charts عبر Plotly.
- تنزيل البيانات بعد الفلترة والإحصائيات إلى CSV.
- واجهة عربية وتصميم متجاوب.

## التشغيل محلياً

يتطلب Python 3.10 أو أحدث.

```bash
# 1) فك ضغط المشروع والانتقال إلى المجلد
cd data_insights_dashboard

# 2) إنشاء بيئة افتراضية (اختياري لكنه موصى به)
python -m venv .venv

# Windows:
.venv\Scripts\activate

# macOS / Linux:
source .venv/bin/activate

# 3) تثبيت المكتبات
pip install -r requirements.txt

# 4) تشغيل التطبيق
streamlit run app.py
```

سيظهر رابط محلي في الطرفية، غالباً `http://localhost:8501`.

## النشر المجاني على Streamlit Community Cloud

1. أنشئي مستودعاً جديداً على GitHub.
2. ارفعي الملفات `app.py` و`requirements.txt` و`README.md` إلى جذر المستودع.
3. سجّلي الدخول إلى [Streamlit Community Cloud](https://share.streamlit.io/).
4. اختاري **Create app** ثم حددي مستودع GitHub والفرع وملف `app.py`.
5. اضغطي **Deploy** وانتظري اكتمال البناء. سيعطيك الموقع رابطاً عاماً للتطبيق.
6. عند تحديث الكود ورفعه إلى GitHub، يعاد نشر التطبيق عادةً تلقائياً.

## النشر على Hugging Face Spaces

1. افتحي [Hugging Face Spaces](https://huggingface.co/spaces) وأنشئي Space جديداً.
2. اختاري SDK من نوع **Streamlit** إن كان متاحاً في إعدادات الإنشاء.
3. ارفعي `app.py` و`requirements.txt` و`README.md` إلى مساحة المشروع.
4. انتظري بناء البيئة، ثم افتحي رابط التطبيق.

إذا لم يظهر خيار Streamlit في إعدادات Space، راجعي إعدادات SDK الحالية في Hugging Face؛ قد تتغير خيارات الاستضافة بمرور الوقت.

## ملاحظات على ملفات CSV
- يفضّل أن تكون الصفوف هي السجلات والأعمدة هي المتغيرات.
- التطبيق يحاول التعرّف على أعمدة التاريخ عندما يحتوي اسم العمود على كلمات مثل `date` أو `تاريخ`.
- إذا كان ملف CSV يحتوي على بيانات شخصية أو حساسة، لا ترفعيه إلى تطبيق عام أو خدمة استضافة قبل التأكد من صلاحياتك وسياسة حماية البيانات.
- المشروع يتعامل مع CSV، ولا يغيّر الملف الأصلي.
